# EgyptianAgent

EgyptianAgent هو نظام مساعد صوتي ذكي موجه بالأساس للمستخدم المصري، خصوصًا كبار السن وذوي الإعاقة البصرية، يعمل محليًا بالكامل على جهاز Android ويستخدم لهجة مصرية طبيعية.

المشروع يقدّم **Hybrid AI Architecture** تجمع بين:

- Fast Path: Intent-based execution باستخدام FunctionGemma-270M (Intent Engine) لأوامر مباشرة وسريعة.
- Slow Path: UI Navigation Engine يعتمد على شجرة الـ Accessibility لتنفيذ مهام متعددة الخطوات داخل التطبيقات.

## أهداف المشروع

- تقديم مساعد صوتي مصري يعمل 100% على الجهاز بدون إرسال بيانات للخارج.
- دعم كبار السن وذوي الإعاقة البصرية بتجربة صوتية سهلة وبسيطة.
- تحقيق أداء عالٍ (latency منخفض، استهلاك بطارية محدود) على أجهزة متوسطة مثل Honor X6c.
- دعم أوامر حياتية يومية: مكالمات، واتساب، منبهات، إعدادات، طوارئ، workflows جاهزة.

## المزايا الأساسية

- دعم wake words خاصة بالمصري: "يا صاحبي"، "يا كبير".
- Intent accuracy ~95% على مجموعة أوامر رئيسية.
- Fast Path latency حوالي 350ms في المتوسط.
- Slow Path latency بين 2–5 ثوانٍ لمهام متعددة الخطوات.
- يعمل حتى مع الشاشة المغلقة كـ system-level assistant.

## طريقة التشغيل (مختصرة)

1. إعداد الجهاز (Honor X6c أو جهاز متوافق، Android 12+، bootloader مفتوح، Magisk للروت).
2. تحميل الكود من GitHub.
3. تحميل نموذج FunctionGemma-270M ونموذج ASR المصري.
4. بناء التطبيق (Release) باستخدام Gradle/السكربتات.
5. تثبيت التطبيق كمساعد نظام / privileged app.
6. إعداد الأذونات (الميكروفون، المكالمات، جهات الاتصال، إلخ).

التفاصيل الكاملة موجودة في دليل التثبيت داخل المستودع (INSTALLATION_REPORT / INSTALLATION GUIDE).
