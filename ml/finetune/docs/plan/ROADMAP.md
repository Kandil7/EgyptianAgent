# Roadmap – EgyptianAgent

## Short-term (v2.x)

- تحسين accuracy لبعض intents.
- تحسين Latency في Slow Path.
- زيادة عدد workflows الجاهزة.
- تحسين TTS المصري.

## Mid-term

- دعم أجهزة إضافية غير Honor X6c.
- modularization أفضل للكود.
- refactor لبعض الموديولات لتصبح أقرب إلى تصميم عام (engine-* modules).
- تحسين أدوات الـ evaluation.

## Long-term

- دعم لهجات عربية أخرى.
- دعم تكامل مع LLMs أخرى كـ fallback.
- تحويل بعض أجزاء المشروع إلى reusable SDK.
- توثيق أوسع للمطورين.
