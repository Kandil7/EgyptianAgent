## Quick Reference

### Voice Commands

#### Activation
| Command | Arabic | Description |
|---------|--------|-------------|
| Wake word | يا صاحبي | Activate assistant |
| Senior wake word | يا كبير | Activate in senior mode |

#### Calls
| Command | Arabic | Description |
|---------|--------|-------------|
| Call mother | اتصل بأمي | Call mother |
| Call father | كلم بابا | Call father |
| Call contact | اتصل بـ [name] | Call any contact |

#### Messages
| Command | Arabic | Description |
|---------|--------|-------------|
| Send WhatsApp | ابعت واتساب لـ [name] | Send WhatsApp message |

#### Alarms
| Command | Arabic | Description |
|---------|--------|-------------|
| Set alarm | نبهني بكرة الصبح | Set morning alarm |

## Troubleshooting Quick Fixes

| Issue | Solution |
|-------|----------|
| App not responding | Check microphone permissions |
| Poor recognition | Retrain with your voice |
| Battery drain | Disable background processing |
| Model not loading | Re-download models |
